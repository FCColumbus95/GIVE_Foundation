# Greater G.I.V.E. Foundation website

Static GitHub-ready website reconstructed from the publicly accessible Greater G.I.V.E. Foundation website content (retrieved 2026-11-10). **This is a recreation, not an exact export of the original site source or artwork.** No FC Columbus files are included.

## Deploy
1. Connect this repository to Cloudflare Pages.
2. In Cloudflare Pages, select **Workers & Pages → Create → Pages → Connect to Git** and select `GIVE_Foundation`.
3. Set framework preset to **None**, build command **blank**, output directory **/** (repository root). Deploy.
4. Test the generated pages.dev address before configuring a custom domain.

## Important
- Donation buttons only draft an email requesting verified payment details. They do not process payments. Connect verified payment processing before advertising online payments.
- The original site logo, flyers, and photographs were not downloadable; the header uses a typographic placeholder.
- Leadership and contact details should be verified before launch.
- No backend, admin panel, or database is included.
